# ASD researcher toolkit - Acceptance

Scenarios an owner or reviewer can run. 1–14 run against `rust/docker-compose.yml` (or the
clinic stack) with `ASD_DATA_KEK` set, `ASD_ALLOW_SYNTHETIC=true`, synthetic sessions from
`asd-cli synth` (with `normCollection.consented = true` for the research ones) and research
logs from `asd-cli gaze synth`; the console in `CURV_API_MODE=live` as `researcher@` unless
stated. 15–18 are iOS; 19–22 are gates. Each cites the spec ids it proves.

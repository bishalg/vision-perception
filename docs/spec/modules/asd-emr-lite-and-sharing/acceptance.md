# ASD EMR-lite record, share-a-case and clinic deployment - Acceptance

Scenarios an owner or reviewer can run. Scenarios 1–12 run against
`deploy/clinic-server/` (or `rust/docker-compose.yml` with `ASD_DATA_KEK` set) and the
console in `CURV_API_MODE=live`; 13–17 against the iOS app and the stack; 18–22 are
operator scenarios on the clinic server. Synthetic sessions (`asd-cli synth`,
`ASD_ALLOW_SYNTHETIC=true`) are the data. Each cites the spec ids it proves.

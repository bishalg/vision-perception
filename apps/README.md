# Applications

This directory contains end-user executable applications and integration demonstrators:

- **`desktop_pipeline_demo/`**: Interactive desktop demonstration application that executes the vision perception pipeline over live webcam feeds or video files with real-time sub-pixel overlay rendering and HUD metrics (backed by `curv_tools_lib::runDesktopDemo`).
- **`cesium_viewer/`**: Phase 4 Vite + CesiumJS digital twin — CCTV pose markers, still panels, OSM globe (no ion token). See [`cesium_viewer/README.md`](cesium_viewer/README.md).
- *Note*: Command-line evaluation and developer CLI tools live in [`tools/`](../tools/) (`curv_cli`, `hand_inspector_cli`, `synth_generator`, `evaluate`, `benchmark`, `video_pipeline_demo`, `live_snapshot_demo`).

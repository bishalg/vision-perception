# iOS Palm Scanner (`apps/ios_palm_app`)

**Xcode application** — palm UI / ViewModels live in this app target.
Shared reusable code comes from packages only.

## Layout

```text
apps/ios_palm_app/
├── AppHost/                 # @main entry + Info.plist
├── Sources/                 # App code (views, controllers, models)
├── PalmScanner.xcodeproj    # Generated by XcodeGen
└── project.yml

apps/mobile_overlay/ios/     # PACKAGE: CurvCameraOverlay + CurvPalmOverlay
adapters/apple/              # PACKAGE: CurvApple (C-ABI Swift wrapper)
```

| Kind | What |
| :--- | :--- |
| **Packages** | Camera overlay kit, palm overlay plugin, CurvEngine wrapper |
| **App** | Vision tracker, ViewModel, scanner UI, capture result, i18n |

## Run on device

```bash
open apps/ios_palm_app/PalmScanner.xcodeproj
```

Signing team is set to Augur Technologies (`5Q924U6M6X`). Select your iPhone → Run.

## Regenerate project

```bash
cd apps/ios_palm_app && xcodegen generate
```

# Hardware & Technology Adapters

This directory houses technology and hardware adapters providing concrete implementations of core abstraction interfaces:

- **`opencv/`**: OpenCV Mat wrappers, color conversion, and image filtering primitives.
- **`onnxruntime/`**: Deep learning inference adapter powered by Microsoft ONNX Runtime C++ API.
- **`tflite/`**: Edge ML inference adapter powered by TensorFlow Lite C++ API.
- **`mediapipe/`**: Hand and landmark estimation model adapters.
- **`android_camera/`**: Android NDK ImageReader / Camera2 native ingestion wrapper.
- **`ios_camera/`**: iOS AVFoundation / Metal buffer ingestion wrapper.
- **`file_image_source/`**: Static image and directory batch frame ingestion.

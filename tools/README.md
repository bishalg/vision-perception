# Developer & Research Tools

Utilities and developer scripts for pipeline execution, accuracy assessment, and visual debugging:

- **`run_pipeline/`**: CLI tool to execute the perception pipeline on single images or directories.
- **`evaluate/`**: Automated metric computation evaluating sub-pixel localization accuracy, RMSE, and false-positive rates.
- **`overlay_viewer/`**: Lightweight utility to render and inspect `PerceptionEvidence` JSON overlays on top of source raster frames.
